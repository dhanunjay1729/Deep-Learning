# Deep Learning Coursework

A collection of assignments I completed during my Deep Learning coursework. Each topic includes an annotated notebook, visual explanations, experiments, and a README describing the work, results, and learning.

| Topic | Work explored |
|---|---|
| [Perceptron and Boolean functions](perceptron-boolean-functions) | Linear decision boundaries and the XOR limitation |
| [Dry Bean classification](dry-bean-classification) | Architecture and training-duration comparisons |
| [Multilabel Yeast classification](multilabel-yeast-classification) | Sigmoid outputs, multilabel metrics, and threshold selection |
| [MNIST optimization and regularization](mnist-optimization-regularization) | Batch size, dropout, checkpointing, and early stopping |
| [CNNs for MRI classification](mri-cnn-classification) | Convolution, global average pooling, and batch normalization |
| [IMDb sentiment with a Simple RNN](imdb-rnn-sentiment) | Sequence length, recurrent capacity, and gradient behavior |
| [GoogLeNet transfer learning](googlenet-transfer-learning) | Feature extraction, fine-tuning, and auxiliary classifiers |
| [Vision model explainability](vision-model-explainability) | RGB permutation, feature ablation, occlusion, and SHAP |
| [RNN temperature forecasting](rnn-temperature-forecasting) | One-hour forecasting, recurrent capacity, and gradient propagation |

The experiments show both successful results and limitations, including optimization failures and tradeoffs between evaluation metrics. Reported performance belongs to the specific coursework datasets and evaluation splits.
